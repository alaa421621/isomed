## Installation Steps

### Step 1: Extract the ZIP File

1. Download `isomed-static-website.zip`
2. Extract it on your computer
3. You'll see one file: `index.html`

---

### Step 2: Upload to cPanel via File Manager

1. **Log in to cPanel**
   - Go to `isomed.net:2083` or your cPanel URL
   - Enter your cPanel username and password

2. **Open File Manager**
   - In cPanel dashboard, find **File Manager**
   - Click to open it

3. **Navigate to Public HTML**
   - Click on **public_html** folder
   - This is where your website files go

4. **Upload the HTML File**
   - Click **Upload** button
   - Select `index.html` from your computer
   - Wait for upload to complete

5. **Verify Upload**
   - You should see `index.html` in the public_html folder
   - Your website is now live!

---

### Alternative: Upload via FTP

If you prefer FTP:

1. **Connect via FTP**
   - Use FileZilla, WinSCP, or similar FTP client
   - Connect to your hosting server
   - Username/password from your hosting provider

2. **Navigate to public_html**
   - Go to `/public_html/` directory

3. **Upload index.html**
   - Drag and drop `index.html` into the folder
   - Wait for upload to complete

4. **Access Your Website**
   - Go to `isomed.net/02/` in your browser
   - Your website is now live!

## Troubleshooting

### White Screen?
- Make sure `index.html` is in the `public_html` folder
- Check file permissions (should be 644)
- Clear your browser cache

### Images Not Showing?
- The images are hosted on cloud storage
- Check your internet connection
- Try a different browser

### Form Not Working?
- The form uses a free service (FormSubmit)
- Make sure your email is correct in the HTML
- Check your spam folder for test emails

### Website Looks Different?
- Clear browser cache (Ctrl+Shift+Delete)
- Try a different browser
- Check on mobile device
